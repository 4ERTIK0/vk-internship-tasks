# Решения заданий для стажировки VK

Задания разделены на две папки:

| Папка | Решение | Состояние проверки |
|---|---|---|
| `01_WukongBenchmark` | C#, автоматизация двух профилей Benchmark Tool, OCR результата, HTML/JSON, восстановление настроек | Сборка и автономные тесты прошли. Реальный Benchmark Tool не установлен. |
| `02_Weather` | Python без внешних пакетов, полный список городов, API wttr.in, статистика стран | Пройден живой запуск 8/8 городов и модульные тесты. |

Начать с README внутри нужной папки. В первой папке есть готовый EXE и исходники, во второй -
скрипт, исходный список городов и фактические результаты запуска. Числа из искусственных
OCR-тестов первой папки не являются результатами Benchmark Tool.
