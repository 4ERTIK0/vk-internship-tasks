# Решения заданий для стажировки VK

Задания разделены на две папки:

| Папка | Решение | Состояние проверки |
|---|---|---|
| `01_WukongBenchmark` | C#, автоматизация двух профилей Benchmark Tool, OCR результата, HTML/JSON, восстановление настроек | Сборка и автономные тесты прошли. Реальный Benchmark Tool не установлен: сквозной прогон не выполнен. |
| `02_Weather` | Python без внешних пакетов, полный список городов, API wttr.in, статистика стран | Пройден живой запуск 8/8 городов и модульные тесты. |

Начать с README внутри нужной папки. В первой папке есть готовый EXE и исходники, во второй —
скрипт, исходный список городов и фактические результаты запуска. Числа из искусственных
OCR-тестов первой папки не являются результатами Benchmark Tool.

**Для сдачи первого задания требуется ещё выполнить реальный прогон на машине с установленным
Benchmark Tool и при необходимости адаптировать навигацию под его интерфейс.** Не следует
утверждать, что он уже проверен: подробности и процедура приёмки находятся в первой папке.

## Ссылки для поля ответа

Публичный репозиторий: **https://github.com/4ERTIK0/vk-internship-tasks**.

- Первое задание: https://github.com/4ERTIK0/vk-internship-tasks/tree/main/01_WukongBenchmark
- Второе задание: https://github.com/4ERTIK0/vk-internship-tasks/tree/main/02_Weather

Скачать весь комплект можно кнопкой **Code → Download ZIP** или командой:

```powershell
git clone https://github.com/4ERTIK0/vk-internship-tasks.git
```

В локальном комплекте также подготовлены два отдельных ZIP и общий архив.
Tesseract и игра в комплект не включаются. Публикация исходников не заменяет сквозную
проверку первого задания, описанную выше.

Краткий текст ко второму заданию:

> Решение: https://github.com/4ERTIK0/vk-internship-tasks/tree/main/02_Weather.
> Python 3.10+, сторонние пакеты не нужны. Запуск: `python weather.py`
> из папки `02_Weather`. Полный исходный список городов включён, результаты и статистика
> вычисляются автоматически через wttr.in. В README есть инструкция и проверочный запуск.

Для первого задания описание запуска и обоснование CPU/GPU-настроек уже подготовлены
в `01_WukongBenchmark/README.md`. Его статус проверки следует обновить только после
успешных двух проходов на реальном Benchmark Tool.
